# **App Name**: Portfolify

## Core Features:

- User Profile: Displays the student's personal information and a brief introduction.
- Skills Showcase: Displays the student's technical and soft skills.
- Projects Display: Shows the student's completed projects with descriptions and links.
- Certifications Display: Displays the student's earned certificates and credentials.
- Contact Form: Enables visitors to contact the student via a web form.
- Admin Authentication: Secure admin login using Firebase Authentication to manage portfolio content.
- Data Storage: Use Firestore to store and retrieve portfolio data.

## Style Guidelines:

- Primary color: Light lavender (#D8CEE6), providing a calm and creative backdrop.
- Background color: Very light lavender (#F4F0F8), ensuring a soft, unobtrusive base.
- Accent color: Soft purple (#A98DCC), for highlighting key elements.
- Body and headline font: 'Inter', a sans-serif providing a modern and readable look.
- Use clean and professional icons to represent skills and categories.
- Use a responsive, single-page layout to ensure accessibility on all devices.
- Use subtle transitions for a smooth user experience.
